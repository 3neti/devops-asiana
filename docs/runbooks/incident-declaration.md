# Runbook: Incident Declaration

**Governing policy:** Incident Management

**Authorized roles:** any observer may raise; designated authority declares and classifies

1. Record the observed condition, source, time, affected service, and known Client impact.
2. Decide whether it is an event, alert, Incident, Major Incident, or Security Incident using current criteria.
3. Assign Incident Commander, Responsible Partner, Technical Lead, and communication owner.
4. Establish an Incident channel and timeline; preserve volatile evidence.
5. Notify required responders and set the next update time.

**Completion:** classification, ownership, communication cadence, and initial evidence are explicit. Classification may change as facts develop.
