# ADR 0002: Begin Documentation-First

- **Status:** Accepted
- **Date:** 2026-08-17

## Context

Premature CRUD would encode ambiguous concepts and create false confidence without an agreed authority model.

## Decision

Establish constitution concepts, policies, procedures, evidence, vocabulary, and boundaries before institutional application features.

## Consequences

The first milestone changes no institutional schema. A later vertical slice must implement tested invariants from this specification rather than generic workflow infrastructure.
