# ADR 0003: Separate Governance, Policy, Procedure, and Evidence

- **Status:** Accepted
- **Date:** 2026-08-17

## Context

Combining institutional authority, requirements, execution instructions, and proof obscures which rule governs and whether it was followed.

## Decision

Treat the Partnership Agreement, policies, procedures and runbooks, and evidence as distinct linked layers.

## Consequences

Authority flows downward and accountability upward. Lower layers cannot amend higher ones; evidence proves events but does not create missing authority.
