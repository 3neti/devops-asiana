# ADR 0007: Treat Operational Evidence as First-Class

- **Status:** Accepted
- **Date:** 2026-08-17

## Context

A control that cannot be demonstrated is unreliable for professional accountability, Client assurance, or learning.

## Decision

Make Evidence Records durable domain objects linked to authority, approval, action, verification, and follow-up.

## Consequences

Evidence receives ownership, classification, retention, integrity, and access controls. Relational and append-only concepts are sufficient; blockchain complexity is rejected.
