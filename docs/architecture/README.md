# Architecture

Architecture in this repository begins with institutional responsibility. Software must make authority, state, history, and evidence explicit without replacing professional judgment or executed legal instruments.

The near-term architecture is a cohesive Laravel application. Domain boundaries organize language and ownership; they are not microservices. New functionality should enter as a narrow vertical slice with domain rules, authorization, evidence, and focused tests.
