# Evidence and Audit Trails

Controls are credible only when the Firm can demonstrate that they occurred. Evidence is therefore a first-class institutional asset, not an attachment added for audit season.

Evidence shall be proportionate, authentic, attributable, time-associated, access-controlled, searchable, linked to its governing record, and retained under an approved schedule. Sensitive evidence may require restricted storage while its metadata remains discoverable.

Git history is useful evidence of documentation changes but is not the approval system for policy, Client, Engagement, access, Change, Incident, or financial decisions.
