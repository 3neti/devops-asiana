# Procedure: Production Access Request

**Governing policy:** Production Access; Engagement; Information Security

**Authorized roles:** requestor, manager or Technical Lead, system owner, delegated access approver

## Procedure

1. Identify the named person, Client, Engagement, environment, system, requested permission, purpose, and duration.
2. Confirm training, device, identity, MFA, and Engagement eligibility.
3. Compare requested privilege with the least permission and shortest duration sufficient for the task.
4. Obtain approval from the system owner and Firm authority required by risk.
5. Provision through the controlled identity or privileged-access mechanism.
6. Verify effective permissions without performing an unauthorized production action.
7. Record expiry and review date; notify the recipient of use and evidence obligations.

**Evidence:** request, reviews, approvals, provisioning log, verification, expiry.

**Escalation:** shared credentials, unsupported MFA, excessive privilege, or missing Client authority go to Security and the Responsible Partner.

**Completion:** access is verified, recorded, and scheduled for expiry or review.
