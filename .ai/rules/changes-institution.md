# Changes Institution

## Scheduled Change Is the Execution Authority Boundary
Only a complete Scheduled Change inside its approved window may set may_execute_change=true. The gate requires an Open Engagement, Client Mandate, operative policies, honest classification, risk, technical review, class-appropriate approvals, viable evidenced recovery, confirmed recovery point, a named executor, and a matching current Active Access Grant.
