# Production Access Institution

## Active Access Is a Fully Resolved Authority
Only a complete Active grant may set may_use_access=true. Named identity, Open Engagement, Client Mandate, Firm and Client approvals, scope, risk, prerequisites, current validity, provisioning, independent verification, logging, operative policies, and complete evidence are separate mandatory gates; authentication or technical possession never implies authority.
